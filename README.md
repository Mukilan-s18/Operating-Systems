## 📌 Project Overview
This repository serves as a comprehensive archive of laboratory experiments and coursework completed for the **Operating Systems** curriculum. It demonstrates practical implementations and theoretical understandings of core OS mechanisms, bridging the gap between hardware architectures and application software.

The assignments document key concepts including process scheduling, memory allocation, inter-process communication (IPC), concurrency, synchronization, and file system management.

## 🛠️ Tech Stack

This coursework heavily involves systems programming and administrative environments:
* **Languages:** C, C++, Bash Scripting
* **OS Environment:** Linux (Ubuntu/Debian)
* **Core Concepts:** Process Management, Pthreads, Semaphores, System Calls

## 🚀 CI/CD Integration

Given that this repository functions primarily as an archive for documentation and final PDF reports, active Continuous Integration and Continuous Deployment (CI/CD) pipelines are currently minimal. However, the repository structure is prepared for future implementations where:
* **GitHub Actions** can be integrated to automatically compile C/C++ source files.
* **Automated Testing** pipelines can validate the output of OS scheduling algorithms against expected test cases.
* **Linting & Formatting** checks can ensure code quality standard compliance prior to merging.
